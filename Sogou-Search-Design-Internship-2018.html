01

Sogou Reading
Book Store Redesign

July-Augest 2018

Introduction:
Conducted UX Research, synthesized key insights and designed user journey map for Product Managers, Designers, and Engineers to redesign the "Book Store" page and "Discover" page.

Challenges:
What is the context when user looking for books to read?
How might we help users find a book more easily?

Outcome:
The CTR(click-through rate) of "Book Store" page increased 28.74% than the previous version.
